# 🕹️ Avatar Adventure Game

A **text-based adventure game** where players explore rooms, collect items, and unlock the Boss Room to win.  
Built in **Python 3.x** as part of an academic project, this game demonstrates fundamental programming concepts such as loops, conditionals, and state management.

---

## 📌 Features
- Navigate through multiple rooms using commands (`north`, `south`, `east`, `west`).  
- Collect items by typing `yes` when prompted.  
- Unlock the **Boss Room** after collecting all required items.  
- Simple, text-driven gameplay with replayability.  

---

## 🛠 Tech Stack
- **Language:** Python 3.x  
- **Concepts:** Loops, conditionals, functions, dictionaries, and input handling.  

---
